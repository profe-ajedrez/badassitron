# M3-A — Experimental unsigned-128 facade (2026-11-17)

**Status: implemented as opt-in source experiment; NOT approved as default or release.**
Starting authority: complete supplied `badassitron_M2E_default_cutover_20261117.zip`.
Badassitron's default `dec128` remains the M2-E Jokruger-backed engine; the
public `dec128/uint128` remains the historical implementation by default.
The separately controlled `badassitron_legacy` decimal rollback is unchanged.

## Implemented

- `-tags badassitron_m3` selects `dec128/uint128/m3_adapter.go` for the complete
  public unsigned arithmetic/bitwise/256-bit division surface, using imported
  `github.com/jokruger/dec128/uint128` primitives. `Lo` and `Hi`, public
  `Uint128`, the historical `errors.Error` codes, and existing import paths are
  preserved. No Go source is copied from upstream and there is no type alias.
- Historical `arithmetic.go`, `bitwise.go` and the 256/192-bit arithmetic in
  `tools.go` are excluded together under the M3 tag. Common historical
  constructors, binary format, textual codecs and zero/constant declarations
  are **deliberately unchanged**, including known conversion behavior. The
  project-owned byte conversion methods were moved unmodified into
  `binary_common.go` for both builds. This is not a dual-engine implementation
  of the same arithmetic method.
- Upstream status codes are mapped to the historical unsigned error codes at
  the public boundary. Simple known-result operations translate their two
  possible statuses directly, avoiding a general mapping function on those
  hot paths. Decimal error translation remains separate and contextual.
- `check-selection.py` tests the entire source-file selection across default,
  M3, legacy decimal, and combined tags. `check-api.py` compares the complete
  AST declaration inventory and **all 66 public `uint128` declarations are
  identical**, including rendered signatures.
- Added an independent deterministic `math/big` suite covering **5,000**
  unsigned operand pairs, **4,000** 256/128 divisions, and **3,000** 192/64
  divisions, including overflow/underflow, bit shifts, sign-free quotient,
  remainder, product halves and binary/text round trips. It runs identically
  in both builds. Added an external-client source-compatibility contract.
- Added separate official-host verification, reproducible benchmarks, and an
  experimental CI workflow. No release tag is created.

## M3 performance — decision to hold default

[Raw local data and paired table](m3-local-bench/comparison.md) use five
samples per variant on the same Go 1.23.2 host, with `GOMAXPROCS=1`, a
0.20s sample duration, and global result sinks to avoid dead-code
elimination. Local median results:

| Operation | Historical ns/op | M3 ns/op | Difference |
|---|---:|---:|---:|
| Add | 0.906 | 1.724 | **+90.3%** |
| MulExact | 1.851 | 1.921 | +3.8% |
| MulOverflow | 2.515 | 3.172 | **+26.1%** |
| QuoRem | 11.830 | 10.960 | −7.4% |
| WideQuoRem | 11.490 | 12.110 | +5.4% |

All five cases have zero heap allocation in both implementations. A direct
upstream delegation can still cost more than the historical inlined code,
particularly for tiny arithmetic. An initial generic state-mapping path was
worse; the small-operation specialized mapping was retained. The results are
**descriptive** and not a Go 1.27.1 regression verdict, but sufficient to
reject automatic promotion in this checkout. No user-facing default or
`dec256`/`dec512` algorithm was replaced in M3-A.

## Decisions and gates

- **Keep:** the historical `uint128` API and its default implementation.
- **Experiment only:** enable Jokruger-backed public arithmetic using
  `-tags badassitron_m3`. Retain rollback via the build tag's absence.
- **Do not switch `uint128` by default** until comparative Go 1.27.1
  benchmarks and source/API/behavioral validation with the exact official
  upstream module are complete and the performance costs are accepted or
  reduced. Internal `dec128` hot paths already use upstream directly; a
  public facade migration is not required for their correctness.
- **M2-E release gates remain open:** this session did not receive a Go 1.27.1
  verification run on M2-E, and the historical source attribution audit is
  still pending. Evidence from M2-D does not certify the changed M2-E tree.
