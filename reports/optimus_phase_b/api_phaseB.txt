package optimus // import "github.com/profe-ajedrez/badassitron/optimus"

Package optimus provides an adaptive fixed-point decimal with the same ordinary
arithmetic API as dec128. Coefficients use the smallest of 64, 128, 256 or 512
bits. Operations never use binary floating-point arithmetic.

Ordinary arithmetic preserves exact results whenever possible; otherwise it
rounds half-even to the highest representable scale (up to 154). Division and
square root use defaultPrecision for non-terminating/irrational results.

    Optimus is an immutable-by-convention value. The coefficient is inline for
    64/128-bit values and indirect only for 256/512-bit values. The pointed-to
