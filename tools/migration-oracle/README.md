# M1 — independent differential oracle

This tool is a **baseline capture and comparison tool**, not a replacement
for API compatibility tests, `math/big` checks, or the upstream implementation.
It runs against the original public `dec128` package, making no assumptions
about its unexported representation.

## What was captured

`testdata/migration/oracle/cases.jsonl` is a seed-fixed set of **3,518**
records, generated by `python3 tools/migration-oracle/generate.py`.
`legacy-results.jsonl` is an actual execution of those cases against
`badassitron_M0_implemented.zip`, using Go 1.23.2 with a **temporary** local
`go.mod` adjustment; the published `go 1.27` declaration was restored.
The source ZIP's original predecessor is `badassitron-master(6).zip`, whose
SHA-256 is recorded in `docs/DEC128_MIGRATION_CONTRACT.md`.

Captured: parse, Add/Sub/Mul/Div, Compare, Canonical, Round, RoundBank,
Rescale, MulRound/DivRound and `WithStatus`, NaN codes 0–10, `ScanInto`,
text/JSON unmarshal; on **every** output the tool also captures `String`,
`StringFixed`, stored scale, sign of zero, NaN, error text, text/JSON marshal,
and `driver.Valuer`. Outputs are compared field-for-field, including null vs
false for status, and failure behavior for scan/unmarshal.

An independent arithmetic check is available:

```sh
python3 tools/migration-oracle/check_exact.py \
  testdata/migration/oracle/cases.jsonl \
  testdata/migration/oracle/legacy-results.jsonl
```

This check uses Python `decimal.Decimal` at 300 digits and verifies only
finite successful Add/Sub/Mul results (not NaN correctness or division).

The fixture includes historical **bugs and quirks**, deliberately; an
observed value is not proof that it is correct. Fixes must be approved in
`docs/MIGRATION_DECISIONS.md` and compared with an independent arithmetic
oracle. The generated cases are deliberately not uniformly random, and
are not exhaustive or a substitute for fuzzing. This tool does not yet
exercise binary codecs or `database/sql` with a real database driver.

## Capture a new candidate

From the candidate module root:

```sh
python3 tools/migration-oracle/generate.py > testdata/migration/oracle/cases.jsonl
GOWORK=off go run ./tools/migration-oracle \
  < testdata/migration/oracle/cases.jsonl > candidate.jsonl
python3 tools/migration-oracle/compare.py \
  testdata/migration/oracle/legacy-results.jsonl candidate.jsonl
```

For true two-process comparison against an immutable original checkout,
run from the working module:

```sh
tools/migration-oracle/run.sh /path/to/original-module /path/to/candidate-module
```

The runner source lives in the candidate repository and is compiled once
in **each** module's own Go build context; no legacy source is copied into
the production module. Both checkouts must have the *same module path* and
must satisfy the installed Go toolchain. Do not run with `go.work` overrides.

A release-approved intentional difference requires an explicit JSON record:

```json
[{"id":"M1-00042","field":"error","decision":"D03","baseline":"overflow","candidate":"inexact"}]
```

Pass that file with `--approved FILE` to `compare.py` or as the optional
third argument to `run.sh`. Unused or stale approvals fail the check. The
example above is illustrative, not an approved deviation.

Test the comparison gate itself:

```sh
python3 -m unittest discover -s tools/migration-oracle -p "test_*.py"
```

## Reproducibility caveats

The baseline was measured with Go 1.23.2 (not the declared minimum Go 1.27).
Do not call M1 or M2 complete until the same suite is repeated on a Go 1.27
host and checked against independently extracted Jokruger v1.4.0.
The current implementation may panic on unsupported state codes; those
are excluded pending the approved D05 fix and its separate test.

## Supplemental M1 corpus (post D04/D05 safety fixes)

The original 3,518-case fixture remains immutable. A second, independently
named suite adds 1,725 deterministic cases for `Mod`, `QuoRem`, `PowInt`, and
`EncodeToUint128`, including a separate remainder result and unsigned
conversion outcomes. Reproduce using:

```sh
python3 tools/migration-oracle/generate_extended.py > testdata/migration/oracle/extended-cases.jsonl
GOWORK=off go run ./tools/migration-oracle < testdata/migration/oracle/extended-cases.jsonl > /tmp/extended-candidate.jsonl
python3 tools/migration-oracle/compare.py testdata/migration/oracle/extended-results.jsonl /tmp/extended-candidate.jsonl
python3 tools/migration-oracle/check_extended.py testdata/migration/oracle/extended-cases.jsonl /tmp/extended-candidate.jsonl
```

The independent checker follows the documented truncating semantics of
`EncodeToUint128`; loss of fractional precision is **counted**, not mistaken
for an exact encoding. See [M1 extension report](../../reports/migration/m1-extension.md).
